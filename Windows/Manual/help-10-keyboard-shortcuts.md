# Keyboard Shortcuts

The menu shows the available shortcut beside each command. Some commands depend on the selected workspace or list items.

## Windows, workspaces and Help

| Command | Shortcut |
| --- | --- |
| Show DownAudible | Ctrl+0 |
| Library | Ctrl+1 |
| Downloads | Ctrl+2 |
| Convert Files | Ctrl+3 |
| Settings | Ctrl+Comma |
| Add Audio Files | Ctrl+O |
| Add Audio Folder | Ctrl+Shift+O |
| DownAudible Help | F1 |
| Close DownAudible | Alt+F4 |

In Setup, press **Ctrl+Shift+B** to go back, **Ctrl+Shift+P** to skip to the final page, and **Ctrl+Shift+M** to open the manual from the final page.

## Navigate without a mouse

Press **Tab** and **Shift+Tab** to move between controls. Use the arrow keys to change the current list row, choice or tab. In a multi-select list, use **Shift** to extend a selection or **Ctrl+Space** to change the selection of the focused item where Windows supports it. **Shift+F10** opens a focused item’s contextual menu where available. **Enter** activates the default action in a dialog. **Esc** closes many dialogs.

Set your preferred screen reader and display options in Windows. DownAudible uses native controls for the main library and transfers lists.
